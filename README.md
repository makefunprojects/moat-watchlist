# Moat Watchlist

Sortable dashboard for a fixed 49-name moat universe.

**Live:** https://makefunprojects.github.io/moat-watchlist/

**As-of:** 2026-09-25 HKT · Source: Yahoo Finance (adjusted close)

**invest_score** = equal-weight percentile ranks of: 10Y CAGR, 5Y CAGR, gap vs 200MA (lower better), Current DD / Max DD, moat_score. RSI is display-only and not in the score.

**Caveat:** Survivorship bias — fixed current universe; does not include delisted or failed names. Not investment advice.
